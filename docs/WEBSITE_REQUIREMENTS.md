# 三角形截面力场预测网站需求文档

## 1. 背景与目标

本项目需要在现有 FD/FL 预测能力基础上建设一个可交互网站。网站面向芯片/微流道截面设计场景，用户只输入三条边长，系统自动生成三角形截面、截面内采样点，并预测每个点的惯性升力、迪恩曳力、合力分布，最终分析聚焦状况和聚焦位置。

本需求文档中的“迪恩业力”按微流控语境理解为“迪恩曳力 / Dean drag force”。如果后续业务侧坚持使用其他术语，前端显示文案可调整，但内部字段应保持稳定。

## 2. 产品范围

### 2.1 本期目标

- 提供一个浏览器可访问的网站页面。
- 用户只需要输入三条三角形边长。
- 自动校验三角形是否合法。
- 自动绘制三角形截面图像。
- 自动生成三角形内部预测点。
- 对每个预测点输出惯性升力 `FL` 预测值。
- 对每个预测点输出迪恩曳力 `FD` 预测值。
- 计算每个预测点的合力。
- 可视化力的空间分布。
- 在一个雷诺数范围内预测当前三角形的聚焦状况，给出可实现聚焦的 `Re` 范围和聚焦位置。
- 支持下载预测结果和图片。

### 2.2 本期不做

- 不要求用户上传 Excel 或手动准备模型特征表。
- 不要求用户理解现有数据 pipeline。
- 不在前端暴露复杂训练参数。
- 不在本期支持非三角形截面。
- 不在本期做在线模型训练，只调用已经准备好的预测模型或模型服务。
- 不承诺每个历史数据批次都能直接用于网站预测，网站只依赖后端整理后的稳定模型接口。

## 3. 用户角色

| 角色 | 需求 |
| --- | --- |
| 芯片/截面设计人员 | 输入候选三角形边长，快速判断该截面是否可能形成良好聚焦。 |
| 建模/算法人员 | 验证不同三角形几何下的力场预测结果，导出点级数据继续分析。 |
| 项目展示人员 | 用图像展示三角形截面、力分布和聚焦位置。 |

## 4. 核心使用流程

1. 用户打开网站。
2. 用户输入三条边长：`AB`、`AC`、`BC`。
3. 系统校验三边是否能构成三角形。
4. 系统根据三边计算三角形坐标、面积、周长、高度、角度等几何特征。
5. 系统在三角形内部生成采样点。
6. 系统把几何特征和采样点坐标提交给后端预测接口。
7. 后端返回每个点的 `FL`、`FD`、合力、聚焦分析结果。
8. 前端展示：
   - 三角形截面图；
   - 内部采样点；
   - 惯性升力分布；
   - 迪恩曳力分布；
   - 合力分布；
   - 聚焦位置和聚焦状态。
9. 用户可下载结果表格和可视化图片。

## 5. 输入需求

### 5.1 用户可见输入

本期前端只暴露以下三个必填输入：

| 字段 | 类型 | 单位 | 说明 |
| --- | --- | --- | --- |
| `side_ab` | number | um | A-B 边长 |
| `side_ac` | number | um | A-C 边长 |
| `side_bc` | number | um | B-C 边长，默认作为底边 |

### 5.2 输入校验

- 三条边必须为正数。
- 三条边必须满足三角形不等式：
  - `side_ab + side_ac > side_bc`
  - `side_ab + side_bc > side_ac`
  - `side_ac + side_bc > side_ab`
- 边长默认单位为 `um`，后端进入模型前统一转换为 `m`。
- 如果输入无法构成三角形，前端应阻止预测，并给出明确错误提示。

### 5.3 后端默认参数

用户界面不暴露这些参数，但后端必须有明确配置：

| 参数 | 默认值要求 | 说明 |
| --- | --- | --- |
| `re_range` | 使用后端配置的雷诺数范围 | 网站需要对多个 `Re` 分别预测，并汇总该三角形在哪个雷诺数范围内可实现聚焦。 |
| `point_count` | 200 | 单个三角形、单个 `Re` 下默认生成 200 个采样点。 |
| `radius_group` | 后端配置或模型默认 | 若 FD 模型依赖半径组，需要后端固定默认值。 |
| `model_version` | 后端配置 | 标识当前使用的 FL/FD/聚焦模型版本。 |

后续版本可以加入“高级模式”，允许研究人员选择 `Re` 范围、采样点数量、半径组和模型版本，但本期默认隐藏。

## 6. 几何生成需求

### 6.1 三角形坐标约定

将 `BC` 作为底边：

- `B = (0, 0)`
- `C = (side_bc, 0)`
- `A = (x_a, z_a)`

其中：

```text
x_a = (side_ab^2 + side_bc^2 - side_ac^2) / (2 * side_bc)
z_a = sqrt(side_ab^2 - x_a^2)
```

系统需要基于该坐标系计算：

- 三个顶点坐标；
- 三角形面积；
- 三角形周长；
- 三个内角；
- 高度；
- 重心坐标；
- 每个采样点到三条边的距离；
- 每个采样点到重心的距离；
- 归一化坐标，如 `x/base`、`z/height`。

前端展示时可把截面平面显示为 `x/y` 坐标；后端内部仍可沿用项目已有的 `x/z` 坐标字段，其中前端 `y` 对应后端截面竖直坐标 `z`。

### 6.2 内部点生成

系统应支持在三角形内部自动生成点，MVP 使用规则网格采样：

- 在三角形外接矩形内生成候选点；
- 使用点在三角形内的几何判断过滤；
- 保留边界点或近边界点时，需要统一规则；
- 每个点需要有稳定 `point_id`。

默认点数为 200 个。后端需要保证这些点稳定分布在三角形内部，并在不同 `Re` 下复用同一组采样点，便于比较力场和聚焦变化。

### 6.3 三角形图像展示

前端需要展示：

- 三角形边界；
- 三个顶点标签 `A/B/C`；
- 内部预测点；
- 聚焦位置标记；
- 可切换的力场色图或矢量箭头。

## 7. 预测需求

### 7.1 惯性升力预测

系统需要对每个采样点预测惯性升力：

| 输出字段 | 说明 |
| --- | --- |
| `fl_x_pred` | 惯性升力在 x 方向上的单方向投影。 |
| `fl_y_pred` | 惯性升力在 y 方向上的单方向投影；后端内部可映射为截面 `z` 方向。 |
| `fl_magnitude_pred` | 基于 x/y 投影计算的惯性升力大小。 |

`FL` 按单方向投影分别展示 x/y 两个方向。网站需要在结果元数据中标记 `fl_output_mode = directional_projection_xy`，前端分别提供 `FL-x`、`FL-y` 和 `FL magnitude` 三个图层。

### 7.2 迪恩曳力预测

系统需要对每个采样点预测迪恩曳力：

| 输出字段 | 说明 |
| --- | --- |
| `fd_x_pred` | 迪恩曳力 x 分量。 |
| `fd_y_pred` | 迪恩曳力 y 分量；后端内部可映射为截面 `z` 方向。 |
| `fd_magnitude_pred` | 迪恩曳力大小。 |

本期 `FD` 明确展示为 Dean force。当前项目历史数据中可能仍存在 `dean_velocity_x/y` 之类旧字段名，后端需要在模型封装层完成字段映射，对前端统一输出 Dean force 语义，并通过 `fd_output_mode = force_vector` 返回。

- `force_vector`：可作为力矢量展示；
- `scalar_projection`：单方向投影。

### 7.3 合力计算

若 `FL` 和 `FD` 都可提供二维分量，合力按点计算：

```text
total_force_x = fl_x_pred + fd_x_pred
total_force_y = fl_y_pred + fd_y_pred
total_force_magnitude = sqrt(total_force_x^2 + total_force_y^2)
```

若某个模型只提供标量或单方向投影：

- 后端仍返回可计算的方向分量；
- 无法可靠计算的分量返回 `null`；
- 前端显示“当前结果为投影/代理量”，不把它标成完整合力矢量。

### 7.4 力分布展示

网站至少支持以下分布图：

- 惯性升力强度热力图；
- 迪恩曳力强度热力图；
- 合力强度热力图；
- 合力方向箭头图；
- 聚焦位置叠加图。

每张图需要支持：

- 色条；
- 鼠标悬停查看点坐标和预测值；
- 切换显示 `FL`、`FD`、合力；
- 导出 PNG。

## 8. 聚焦分析需求

### 8.1 聚焦状态定义

网站需要输出一个整体聚焦判断：

| 状态 | 说明 |
| --- | --- |
| `focused` | 预测存在明确稳定聚焦位置。 |
| `weak_focus` | 存在可能聚焦区域，但稳定性或置信度不足。 |
| `not_focused` | 未发现明确聚焦位置。 |
| `unknown` | 模型输出不足，无法判断。 |

前端中文显示建议：

- `focused`：聚焦良好
- `weak_focus`：弱聚焦/可能聚焦
- `not_focused`：不聚焦
- `unknown`：暂无法判断

### 8.2 聚焦位置计算

聚焦位置可以由以下方式之一给出：

- 由专门聚焦模型直接预测；
- 根据合力大小最小区域推断；
- 根据力场方向收敛区域推断；
- 根据规则和模型组合推断。

输出字段：

| 字段 | 说明 |
| --- | --- |
| `focus_status` | 聚焦状态。 |
| `focus_x` | 聚焦点 x 坐标，单位 um。 |
| `focus_z` | 聚焦点 z 坐标，单位 um。 |
| `focus_region` | 聚焦区域点集或轮廓，可选。 |
| `focus_re_range` | 预测可实现聚焦的雷诺数范围。 |
| `focus_confidence` | 0 到 1 的置信度。 |
| `focus_reason` | 简短解释，例如“合力低值区集中在截面右上区域”。 |

聚焦判断实现方式暂定。后端接口需要预留 `focus_method` 字段，取值可以是 `classifier_model`、`force_rule` 或 `hybrid`，等模型方案确认后再固定默认实现。

### 8.3 聚焦可视化

前端需要在三角形图上叠加：

- 聚焦点；
- 聚焦区域；
- 状态标签；
- 置信度；
- 简短解释。

## 9. 页面需求

### 9.1 主页面布局

主页面分为三个区域：

1. 输入区：三条边长输入和预测按钮。
2. 可视化区：三角形截面、点、力分布和聚焦位置。
3. 结果区：关键数值、聚焦判断、下载按钮。

页面需要支持中英文切换。默认语言为中文，用户可在页面右上角切换为英文；切换后输入标签、按钮、图例、状态提示、错误提示、结果摘要和下载说明都应同步切换。

### 9.2 输入区

必须包含：

- `AB` 输入框；
- `AC` 输入框；
- `BC` 输入框；
- 单位标识 `um`；
- “生成并预测”按钮；
- 输入错误提示。

### 9.3 可视化区

必须包含：

- 三角形截面图；
- 图层切换：
  - 采样点；
  - `FL`；
  - `FD`；
  - 合力；
  - 聚焦区域；
- 鼠标悬停信息。

### 9.4 结果区

必须包含：

- 三角形面积；
- 三角形周长；
- 高度；
- 三个角度；
- 采样点数量；
- 聚焦状态；
- 聚焦坐标；
- 最大/最小/平均 `FL`；
- 最大/最小/平均 `FD`；
- 最大/最小/平均合力；
- 下载 CSV；
- 下载 PNG。

## 11. 数据与模型对接需求

网站后端需要封装一个稳定预测服务，不让前端直接依赖历史 Excel 字段。

### 11.1 模型输入特征

后端根据三条边和采样点自动生成模型特征：

- 边长；
- 周长；
- 面积；
- 高度；
- 三个角度；
- 点坐标；
- 点到三条边的距离；
- 点到重心的距离；
- 归一化坐标；
- `Re` 范围内的每一个雷诺数；
- 必要的交互特征。

### 11.2 模型输出标准化

无论底层模型使用什么字段名，后端对前端只输出统一字段：

- `fl_x_pred`
- `fl_y_pred`
- `fl_magnitude_pred`
- `fd_x_pred`
- `fd_y_pred`
- `fd_magnitude_pred`
- `total_force_x`
- `total_force_y`
- `total_force_magnitude`
- `focus_status`
- `focus_x_um`
- `focus_y_um`
- `focus_re_range`
- `focus_confidence`

### 11.3 模型版本记录

每次预测结果必须包含：

- 模型版本；
- 特征版本；
- 默认参数；
- 预测时间；
- 输出物理含义标记。

### 12.2 图片下载

用户可下载当前可视化图，至少支持：

- 三角形点图；
- `FL` 分布图；
- `FD` 分布图；
- 合力分布图；
- 聚焦分析图。

下载文件中的字段名保持稳定英文机器字段；界面上展示的字段解释和导出说明需要随中英文切换变化。

## 13. 性能需求

- 三边输入后，基础几何图应在 1 秒内生成。
- 默认采样密度下，完整预测建议在 10 秒内返回。
- 如果预测超过 10 秒，前端应显示加载状态。
- 单个三角形、单个 `Re` 下默认预测 200 个点。
- 后端应缓存模型，避免每次请求重新加载模型。

## 14. 错误处理

| 场景 | 处理 |
| --- | --- |
| 三边不能构成三角形 | 前端提示“输入边长无法构成三角形”。 |
| 边长为空或非数字 | 前端提示具体字段错误。 |
| 后端模型未加载 | 返回模型不可用错误，前端提示稍后重试。 |
| 预测结果部分缺失 | 前端展示可用结果，并提示哪些分量不可用。 |
| 聚焦无法判断 | `focus_status = unknown`，前端显示“暂无法判断”。 |

## 15. 验收标准

本期网站完成应满足：

- 用户只输入三条边即可完成一次预测。
- 非法三角形会被阻止提交。
- 页面能正确绘制三角形和内部采样点。
- 后端能在配置的 `Re` 范围内返回点级 `FL`、`FD`、合力和聚焦结果。
- 页面能切换查看 `FL`、`FD`、合力分布。
- 页面能标出聚焦位置、可聚焦 `Re` 范围，或说明无法判断。
- 页面支持中英文切换，且主要操作文案、错误提示、图例和结果摘要均能正确切换。
- 结果可下载为 CSV。
- 当前图像可下载为 PNG。
- 响应中包含模型版本和输出物理含义说明。
- Dean 输出在网站语义中明确为 Dean force；若底层模型仍使用旧字段名，必须由后端完成语义映射和说明。
- 网站需要按服务器部署要求设计，支持多人通过浏览器访问。

## 16. 后续迭代

- 增加高级参数：`Re` 范围、半径组、采样点数量、模型版本。
- 支持批量输入多个三角形。
- 支持对比多个三角形的聚焦结果。
- 支持导出完整分析报告。
- 支持保存历史预测记录。
- 支持在线切换不同训练批次或模型。
- 支持三角形以外的截面形状。

## 17. 已确认与待定问题
