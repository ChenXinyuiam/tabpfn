# FD/FL 聚焦判定预测项目需求文档

## 1. 背景

为了辅助微流控芯片设计，本项目需要预测通道截面中每个采样位置对应的聚焦判定情况。

当前采用两阶段建模路径：

1. 先预测与聚焦判定最相关的两个物理量：
   - `FD`：Dean drag force / 迪恩曳力相关量。
   - `FL`：inertial lift force / 惯性升力相关量。
2. 再基于预测得到的 `FD`、`FL`，结合几何、位置、流动条件等特征，预测最终聚焦判定结果。

聚焦判定目标是 3 分类问题，类别为：`好聚焦`、`次聚焦`、`不聚焦`。当前首要问题不是模型精度不足，而是数据来源、字段含义、数据处理流程和模型流程不够清晰，导致 pipeline 难以稳定复现。

## 2. 项目目标

第一阶段目标是跑通并规范整个 pipeline，而不是追求最终最优模型。

本阶段需要达到：

- 构建清晰的数据 pipeline：从原始数据到模型可用数据。
- 构建清晰的模型 pipeline：从特征数据到 `FD/FL` 预测，再到聚焦判定分类。
- 明确输入字段、目标字段、生成字段、输出文件和中间产物。
- 使用 TabPFN 跑通 `FD` 回归、`FL` 回归和聚焦判定分类流程。
- 产出基础验证报告，用于证明 pipeline 已成功运行，并暴露剩余数据质量问题。

## 3. 第一阶段非目标

第一阶段暂不要求：

- 部署线上系统或构建 Web UI。
- 证明 TabPFN 是最终最优模型。
- 达到最终科研发表级别的模型精度。
- 自动兼容所有历史 Excel 变体。
- 把所有探索性脚本重构为完整工程包。
- 支持当前三角形截面之外的其他芯片几何，除非后续明确需要。

## 4. 使用者与使用场景

主要使用者：

- 研究者 / 建模人员：整理数据、训练模型、评估模型。
- 芯片设计者：希望输入候选截面位置后，获得对应聚焦状态预测。

核心使用场景：

- 给定一批原始 `FD/FL/focus` 数据，标准化为模型可用数据。
- 给定模型可用数据，训练或评估 TabPFN 的 `FD/FL` 回归模型。
- 给定几何、位置和流动条件特征，预测 `FD`、`FL` 和最终聚焦类别。
- 查看数据质量、特征完整性、模型指标和逐点预测结果。

## 5. 核心定义

### 5.1 预测目标

| 目标 | 类型 | 说明 |
| --- | --- | --- |
| `FD` | 回归 | Dean drag force，弯曲通道中 Dean 二次流 / Dean 涡对颗粒产生的横向拖曳力，会改变颗粒在截面内的迁移和平衡位置。未做数据处理时单位为 N。 |
| `FL` | 回归 | inertial lift force，有限 Reynolds 数通道流中作用于颗粒的横向惯性升力，通常可理解为剪切梯度升力和壁面诱导升力的合力。`FL` 本质为矢量；当前第一阶段目标为一个方向上的投影。未做数据处理时单位为 N。 |
| `focus_label` | 3 分类 | 聚焦判定标签，取值为 `好聚焦`、`次聚焦`、`不聚焦`。标签生成方法仍待研究员确认。 |

### 5.2 特征分组

| 特征组 | 示例 | 要求 |
| --- | --- | --- |
| 几何特征 | 底边、高、边长、面积、周长、角度 | 每个样本必须具备。 |
| 位置特征 | `X`、`Z`、可选 `Y` | 每个截面采样点必须具备。 |
| 距离特征 | 到底边、左边、右边、重心的距离 | 如果进入模型特征集，则必须稳定生成。 |
| 流动条件 | Reynolds number / `Re` | 每个样本必须具备。 |
| 工程特征 | 比值、角度差、归一化距离、交互项 | 由 pipeline 生成，不手工维护。 |
| 阶段一预测 | `FD_pred`、`FL_pred` | 由回归模型生成，用于阶段二分类。 |

### 5.3 坐标系约定

截面坐标系需要按三角形类型统一定义，避免同一物理位置在不同样本中被编码成不可比较的 `X/Z`。

锐角三角形：

- 原点设在三角形左下角顶点。
- 底边方向为 `x` 轴正方向。
- 垂直底边向上方向为 `z` 轴正方向。
- 该定义应确保三角形区域位于第一象限。

钝角三角形：

- 底边仍作为 `x` 轴。
- 当三角形左下角角度大于 90 度时，原点需要沿底边方向移动，使 `z` 轴经过上顶点。
- 换言之，上顶点在该坐标系下应满足 `x = 0`，`z > 0`。
- 该坐标系用于保证钝角三角形的几何表达和位置特征稳定，而不是强制所有点都位于第一象限。

该坐标系约定应写入数据 manifest，并在数据标准化阶段完成，不应由训练脚本临时推断。

## 6. 数据 Pipeline 需求

### 6.1 预期数据流

```text
原始数据
  -> 标准化 rawdata
  -> 清洗数据
  -> 单位缩放 / 归一
  -> 计算几何与距离特征
  -> 生成模型可用特征数据
  -> 生成训练 / 测试划分
  -> 训练 / 评估模型
  -> 保存预测结果、指标和运行清单
```

### 6.2 目录约定

项目应收敛到以下目录契约：

```text
data/
  rawdata/<batch>/
    originals/              # 可选，保存原始交付文件
    standard/
      samples.csv           # 必需，标准化后的逐点样本表
      manifest.json         # 必需，批次元数据和质量摘要
      files.csv             # 可选，原始文件到标准样本的映射
  interim/
    cleaned/
    scaled/
    features/
  processed/
  triangle_groups_fixed_v2_focus/
    combined/
models/
results/
outputs/
```

批次名使用稳定日期格式，例如 `2026-06-01`。

### 6.3 标准样本表约定

`samples.csv` 中每一行代表一个几何 / 流动条件下的一个截面采样位置。

必需标识字段：

- `sample_id`
- `batch`
- `source_file`
- `geometry_id`
- `point_index`

必需几何、位置、流动条件字段：

- 底边长度
- 高度
- 边长，或足以计算边长的信息
- 面积
- 周长
- 三个角度
- `X`
- `Z`
- `Re`

目标字段按任务要求存在：

- `FD` 回归任务需要 `FD`。
- `FL` 回归任务需要 `FL`。注意：当前交付表格中的列名为 `FL`，但实际含义是 `FLx`，即 `FL` 矢量在一个方向上的投影；后续需要在数据标准中明确该方向和符号约定。
- 聚焦判定任务需要 `focus_label`。

允许某些数据批次只包含部分目标，但 `manifest.json` 必须说明该批次包含哪些目标。

### 6.4 数据校验需求

进入模型 pipeline 前，至少需要校验：

- 必需字段存在。
- `sample_id` 不重复。
- 数值字段可以被正确解析。
- 几何量物理有效，例如底边、高度、面积、`Re` 均为正。
- 三角形角度和约等于 180 度。
- 位置点位于目标截面内，或明确标记为允许的边界 / 外推点。
- `X/Z` 坐标符合第 5.3 节的坐标系约定。
- 当前任务所需目标字段非空。
- `focus_label` 只包含批准的 3 个类别。
- 单位转换规则明确，并写入 `manifest.json`。

默认情况下，关键校验失败应阻止进入训练流程；只有明确标记为 warning 的问题才允许继续。

## 7. 模型 Pipeline 需求

### 7.1 阶段一：FD/FL 回归

使用 TabPFN 分别训练或评估：

- `FD`
- `FL`

要求：

- 使用一套明确批准的阶段一特征列表。
- 训练集和测试集使用一致的数据预处理。
- 保存每折指标和加权汇总指标。
- 保存足以复现实验的元信息，包括数据路径、特征列表、目标、变换方式、fold 数和模型设置。

当前建议指标：

- MSE
- MAE
- R2
- MAPE
- SMAPE

### 7.2 阶段二：聚焦判定 3 分类

聚焦判定分类器应使用：

- 几何、位置和流动条件特征。
- `FD_pred`
- `FL_pred`

输出为 3 分类 `focus_label`。

要求：

- 默认沿用阶段一的 fold 划分，除非明确批准其他划分方式。
- 测试集分类特征中不能泄漏真实 `FD/FL`，除非该实验被明确标记为 oracle baseline。
- 保存每折分类指标。
- 保存逐点预测结果，包括真实标签、预测标签和类别概率。

当前建议指标：

- Accuracy
- Precision
- Recall
- F1
- Confusion matrix
- Macro / weighted 指标，适配 3 分类问题。

## 12. 文献定义依据

需求文档中的 `FD/FL` 物理定义参考惯性微流控领域的通用定义：

- `FL` / inertial lift force：有限 Reynolds 数微通道流中，颗粒受到的横向惯性升力；常由剪切梯度升力和壁面诱导升力共同构成，二者平衡决定颗粒在截面中的迁移和平衡位置。
- `FD` / Dean drag force：弯曲微通道中由于通道曲率产生 Dean 二次流，二次流对颗粒施加横向拖曳力，进而改变惯性聚焦平衡位置。
- 对本项目而言，文献定义只用于统一物理概念；训练数据中每一列的具体方向、符号和投影含义仍以数据标准和 manifest 为准。

## 13. 当前风险

- 历史原始文件可能存在列名、单位、编码和目录结构不一致。
- 现有代码中的中文字段在部分环境下可能出现乱码。
- 当前聚焦推理代码部分逻辑更接近二分类，而需求目标是 3 分类。
- 阶段二分类容易发生数据泄漏，尤其是真实 `FD/FL` 被误用于测试集分类特征时。
- TabPFN 本地模型文件较大，不能直接进入 Git，需要单独管理。
- 探索性脚本中可能包含尚未文档化的隐含假设。
