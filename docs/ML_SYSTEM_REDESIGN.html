01 / DESIGN REVIEW

需要先解决的六个设计问题

问题为什么会影响结果建议决策
五折的拆分单位同一三角形的不同点、Re、镜像和插值数据高度相关。随机分行会让测试集包含训练时已经见过的几何。新三角形任务以物理几何族分组做外层五折；空间补点另用空间分组评估。
FD 的物理量未定当前维护代码预测 FD 文件中的 u。仓库明确记录其物理含义与单位未确认，不能据文件名直接认定是力。[S2]暂存为 FD_u；确认目标量、单位、分量和必要的转换参数后，再启用力合成。
Fzong 的定义现有聚焦特征依赖 Fzong 正负号。向量模长恒非负，无法替代有符号分量；fl、flx、fly也不能直接混用。固定 Fzong 是哪个方向的合力、投影或其他量；统一坐标系、符号约定和目标单位。
缺少模型产物环节五折会得到五个验证模型，但推理需要明确使用哪个版本、训练数据和特征配置。独立管理模型配置与训练快照；评估通过后按冻结方案拟合发布版本，或明确采用已评估的折模型集成。
上游误差传到分类器从真实 Fzong 提取的边界较干净，而预测场的零交叉、符号和边界可能偏移。分类器单独成绩不能代表整条链。同时报告真实场分类与预测场端到端分类；预测场训练特征必须用分组折外预测生成。
二分类还是三分类当前维护模块只接收 F/UF；历史模块把 WF/F 合并。两者都不是独立的 WF、F、UF 三分类。[S5]第一版可沿用 F/UF；若需三类，要提供三类人工标签，并同步升级训练、概率输出、校准和指标。

当前仓库已恢复 src/data，并拥有维护中的 src/regression 与 src/focus_inspection。本方案以当前文件为依据，未沿用早期目录缺失的结论。

02 / ARCHITECTURE

三条工作流，共享一套基础能力

能力边界输入 → 输出职责约束
数据审核与标准化文件 / 几何请求 → 规范数据 + 审核报告按任务检查必需列；确定性规范化有记录；不自动补造监督标签。
几何、格点与特征顶点、坐标、工况 → 查询位置与 X计算距离、归一化坐标等；版本化边界、坐标及采样规则。
模型适配与产物训练 X/y 或查询 X → 模型包 / 预测FD、FL、聚焦分别有明确任务和输出；保存训练上下文与预处理器。
评估数据快照 + 模型配置 + 划分 → 折外预测 + 指标掌握拆分、内层选型和比较协议；测试集不参与任何拟合与选择。
物理转换已确认的预测物理量 + 参数 → Fzong检查量纲、分量和点位对应；版本化公式及适用条件。
Pipeline 编排运行请求 + 模型包 → 完整结果包负责步骤顺序、失败传播、缓存和产物记录；不复制各模块算法。
报告与追溯审核、预测、指标、版本 → 表格 / 图 / HTML可从已有数值结果重建报告；禁止把无真值预测描述为准确率。

先在现有 Python 工程内保持这些边界即可。每个模块不必对应一个服务，也不需要一开始引入分布式调度。

03 / DATA CONTRACT

把数据类型、样本单位和学习信号写清楚

任务一条学习样本输入 X监督信号 y
FD 回归某几何、工况、空间位置的一个点几何描述、朝向、Re、曲率半径 R、x/z、边界距离；需要时加入粒径与流体参数真实仿真或实验提供的 u 或已确认的力分量；目标身份不能混淆
FL 回归某几何、工况、空间位置的一个点共享几何与工况特征；明确对应目标分量独立参考的 fl / flx / fly，按任务分别建模
聚焦分类一个完整截面工况Fzong 场的边界宽度、位置、符号比例、空间统计，以及几何 / R / Re独立人工、实验或高可信参考标签：F/UF 或 WF/F/UF
Fzong 合成同一工况同一点的物理量已对齐且定义一致的 FD、FL、必要物理参数通常为确定性计算；若评估合成误差，仍需独立参考 Fzong

当前分类代码的样本键是 source_file + R + re。新设计建议建立稳定 sample_id，连接几何、朝向、工况及重复实验 ID；文件名仅作来源。一个截面的几千个点最终贡献一个聚焦标签。

训练数据集

  • 至少有多个几何族，才能学习并验证跨三角形泛化。
  • FD / FL 可来自不同采样位置，分别利用各自原始标签训练；统一查询网格后对齐预测。
  • 同一物理样本跨文件、重复导出和派生数据要有共同的来源关系。
  • 不能使用分类规则自动生成标签，再把对该规则的拟合当作真实聚焦识别能力。

预测请求

  • 新三角形顶点，或可唯一重建三角形的参数、朝向和坐标约定。
  • Re 列表、曲率半径及单位；若粒径 / 材料参数变化也必须显式给出。
  • 格点分辨率、边界规则，或直接提供查询坐标。
  • 预测请求可没有 FD、FL 和聚焦标签；没有真值时只输出预测与覆盖诊断。

建议的身份与单位字段

dataset_id, source_file, source_hash, source_row, schema_version
geometry_id, geometry_family_id, orientation, coordinate_frame
sample_id, point_id, re, curvature_radius, particle_radius
x, z, length_unit, area_unit, target_name, target_unit, component
value_origin: measured | simulated | interpolated | predicted
parent_ids, transform_version, model_version

以上是目标数据契约，不是现有代码的完整字段清单。曲率半径 R 与粒子半径必须分开；几何尺寸分组与“同形不同尺度”分组也应分别定义。

04 / DATA AUDIT

审核是准入门槛，标准化是有记录的转换

  1. 登记原始输入保留原文件、批次、哈希和提供者说明；识别 FD、FL、Fzong、标签表或纯几何请求。原始数据只读。
  2. 检查结构与数值核对必需列、重复列、数值可解析性、NaN / Inf、唯一键。训练任务缺失 y 时隔离相关记录；预测任务允许没有 y。
  3. 检查单位与物理语义显式声明 m / mm / um；已经是 um 时转换倍率为 1。面积按平方倍率处理；速度与力分别管理。未知单位不得仅凭数值大小自动放行。
  4. 检查几何与坐标三角形非退化、边角高相互一致；验证点在三角形内部、坐标原点与镜像变换。字段提供的距离与重算距离不一致时保留差异。
  5. 检查重复、覆盖和标签重复坐标区分完全重复、重复测量和冲突值；统计每个 R/Re 的点数、空间覆盖与标签数量。标签匹配必须一对一。
  6. 生成准入结论与快照输出 ACCEPT / REVIEW / REJECT 及原因。标准化后的数据与审计表一起版本化；修复规则显式记录，不能静默改标签、镜像符号或异常值。

审核分两层：输入审核检查格式、物理量与几何是否自洽；推理适用性检查输入是否超出某个模型的几何、Re、R 和空间支持范围。新三角形本来就可能超范围，应该标注外推风险，而不是一概判成坏数据。

建议输出 audit.json、issues.csv、accepted_points、rejected_rows 和 manifest.json。缺失值插补器、缩放器等依赖数据统计量的步骤放到每折训练内部；列名映射、明确单位换算等确定性步骤可先完成。

05 / EVALUATION

五折是一种配置，评估问题决定怎么拆分

评估请求至少包含 dataset_id + task + model_config + split_protocol + metrics。比较不同模型时使用同一数据快照、同一划分、相同训练采样规则与可比预算。

想回答的问题划分协议适用结论
同一个三角形补新位置按空间位置或连续空间区域分组；相关重复点和派生点不可跨折已知几何的空间预测；若要证明空间外推，应专门留出边缘 / 区域
从已知三角形预测新三角形几何族 GroupKFold(5)；镜像、全部 R/Re、所有 FD/FL/Fzong 来源按同一几何表分配未知几何泛化；严格参数域外外推还需专设尺寸 / 角度超范围测试
新 Re 或新曲率半径另设工况留出，尤其留出训练范围以外的值工况泛化；不能由几何五折成绩替代
新批次 / 新来源数据批次或提供者留出，按研究目的同时控制几何重叠数据来源变化下的适用性

指标分层报告

层级主要指标统计口径
FD / FL各目标分别报告 R²、MAE、RMSE；辅以符号错误率、近零区域误差保留原目标单位。报告各折、各几何、各 Re、几何等权汇总和汇总 OOF，避免密集点几何主导结果。
Fzong同点误差、符号一致率、零交叉 / 边界位置误差；矢量可另评方向物理定义确认且存在参考场才能评估；不能拿自己的 FD/FL 预测合成结果充当真值。
聚焦Macro-F1、balanced accuracy、各类别 precision/recall、混淆矩阵样本单位为截面工况；二分类可补 PR-AUC / ROC-AUC，三分类按明确的多类口径计算。
概率与运行Log loss、Brier / 校准图、复核比例、有效预测覆盖率、耗时与资源概率不等于可信度证明。阈值与校准仅在训练侧选定；剔除失败样本时必须报告完整分母。

R² 可以为负；目标恒定或测试样本不足时应标记不可解释 / 不可用。五折标准差不是独立重复实验的置信区间；不确定性估计应以几何为重采样单位。验收阈值由用途与误差容忍度预先约定。

全链路评估：每个外层测试几何在所有模块中都要不可见

  1. 先按几何分配外层训练集与测试集，FD、FL、Fzong、聚焦标签和派生数据共用这张划分表。
  2. 在外层训练集内部做分组交叉拟合：用其他内层几何训练 FD/FL，预测被留出的内层几何，形成训练侧的折外预测场。
  3. 从这些折外预测场合成 Fzong、提取截面特征，再用独立标签训练聚焦模型。若选择特征、超参数或概率阈值，内层验证样本也不能参与相应上游模型拟合；必要时增加一层交叉拟合。
  4. 用全部外层训练数据拟合上游模型，生成外层测试几何的力场；沿相同网格和特征协议做聚焦预测。
  5. 只在最后对比外层真值，汇总五折的回归、Fzong 和聚焦结果。另设真实 Fzong 输入的分类基线，观察上游误差带来的变化。

不能先在全量数据上插值 / 拟合 FD、FL，再做分类五折。这样测试几何的信息可能已进入上游模型。所有使用标签或统计量的数据处理、加点、调参和模型选择必须服从完整链路的划分。

若没有可关联的 FD/FL 训练数据、Fzong 定义与截面聚焦标签，可以先完成各模块独立评估，但应将端到端聚焦能力标记为“待验证”。

06 / INFERENCE

新三角形的一次预测应该这样运行

  1. 读取请求与模型版本输入三角形、朝向、Re 列表、R 及单位、必要物理参数、网格配置。选择与任务、特征版本及分量一致的 FD / FL / 聚焦模型包。
  2. 审核几何并生成查询格点重建真实三角形顶点，生成水平分层规则网格或接受外部坐标；裁剪到内部并保留固定 point_id。各 Re 可共用同一坐标集合。
  3. 计算共享特征与适用性诊断计算边长、角度、面积、距离、x/H 与 z/H 等。检查新几何与训练几何的差异、Re/R 超范围情况和空间覆盖；坐标变换时分量和符号必须同步。
  4. 分别预测 FD 与 FL加载模型和训练侧预处理器，对同一查询表推理。第一版建议两条回归支路独立，特征均能在推理时获得。
  5. 经过物理转换合成 Fzong先核验物理量、单位、分量和坐标系，再按确认公式计算。若 FD 实际为速度，必须先调用已验证的速度到力转换；缺参数则保留上游结果并停止该分支。
  6. 按截面工况提取特征并分类按 sample_id 聚合完整力场，复用训练时的平滑、边界宽度 / 位置与统计定义；输出类别、各类概率、review_status 和原因。
  7. 保存结果、诊断与可追溯信息导出点表、截面判定表、场图和 HTML；记录请求、数据 / 模型 / 特征 / 物理公式版本、覆盖率、无效点和运行日志。
FD_branch(X_query) → FD_u 或已确认的 FD 分量
FL_branch(X_query) → 已确认的 FL 分量
Fzong = physical_adapter(FD_output, FL_output, physical_parameters)

只有在同一方向、相同单位、相同坐标约定且没有遗漏相关力项时，才能采用 Fzong_component = FD_component + FL_component。现有字段名 Fzong / Fzong2 本身不足以证明该定义。

两条允许的快捷入口：已有查询坐标可跳过网格生成；已有合规 Fzong 场可直接进入截面特征与聚焦推理。每次输出必须标注实际走过的路径。

目前 fd-from-fl 使用插值 FL 辅助预测 u，属于另一种依赖结构。若未来选用这种模型，应明确为 FL → FD → Fzong 的有向流程，用折外 FL 特征训练下游；不要同时让 FD 和 FL 互相依赖而形成循环。

07 / GRID & INTERPOLATION

生成查询格点和插值生成标签，是两件不同的工作

操作放在哪里生成什么评价方式
新三角形查询网格推理时，几何审核后、模型预测前坐标与几何特征，没有 y检查内部点、边界、密度、重复和点序；不会凭空增加训练信号
基于原始场插值加点可选训练增强，只能在相应训练折内生成原始点派生的伪标签及来源只用独立原始真值评估；记录方法、父数据和外推标记
TabPFN 预测加点用训练侧模型预测新位置模型预测值，来源为 predicted同样不是独立真值；用它训练另一模型时属于蒸馏 / 级联方案，需单独评估
绘图平滑与重采样报告层，或已冻结的截面特征协议展示场或一致采样场不能隐藏无覆盖区域，也不能拿平滑后的结果替换原始测试真值

网格规则会影响聚焦特征

当前边界特征按相同 z 的水平行排序，并使用三点中值平滑。[S6] 因此第一版宜采用水平分层网格，并明确 x/z 间距、边界是否纳入、原点、方向和每层采样。任意随机散点未必满足现有特征算法的输入假设。

  • 训练与推理采用一致的采样 / 重采样协议；非均匀采样时说明符号比例的权重，避免稠密区域主导统计。
  • 用粗、中、细三个分辨率检查边界特征、Fzong 符号分布和分类概率是否稳定；网格变化会同时改变三点平滑的物理尺度。
  • 若启用相邻点补点，水平 / 竖直中点与单元中心分开定义；四角齐全才生成该单元中心，并用坐标容差去重。
  • 零附近的符号可能受数值误差影响，可设计带物理单位的零容差，但必须版本化，并在训练侧验证后固定。

单个三角形内的凸包覆盖不能证明跨三角形预测可靠。新几何还需要特征域诊断与几何留出验证。

模型包至少包含：任务与类别定义、checkpoint 身份、训练数据 / 上下文快照、特征清单与预处理状态、版本与依赖、训练范围、物理公式版本、评估协议和关联报告。对于当前 TabPFN 配方机制，保存一个 checkpoint 路径并不足以复现预测，还要固定训练上下文及配置。

两种输出粒度：点表以 sample_id + point_id 连接坐标、FD、FL、Fzong 和状态；聚焦表每个截面工况一行，包含 predicted_label、各类概率、review_status 和原因。REVIEW 是操作状态，不是额外的物理聚焦类别。

失败处理：部分点失败时输出明确状态和覆盖分母；不能用零填充缺失力。物理转换不可用时，返回已完成的 FD_u / FL 与原因，并将下游标记为未执行；模型不可用时不自动把经验公式伪装成模型预测。

缓存身份：输入内容、点序、模型、预处理、网格、特征和物理公式版本共同决定缓存键；支持复用数值结果重新绘图。

10 / IMPLEMENTATION

按可以验收的里程碑推进

P0 · 明确任务与物理定义

确认 FD-u 是什么、各 FL 分量与单位、Fzong 公式、R 的含义与单位、F/UF 或 WF/F/UF 标签目标。形成带版本的数据字典。

验收：一组已知输入可人工复算，坐标 / 单位转换与物理量定义一致。

P1 · 统一审核与几何身份

为 FD/FL/Fzong/标签表和几何请求增加任务契约，复用审核与单位代码，输出可追溯快照；建立跨文件几何和样本关联。

验收：重复、单位冲突、坏几何、标签错配均产生明确记录；m 与 um 表达同一几何时标准结果一致。

P2 · 建立可信评估基线

固定几何五折与空间协议，比较基线回归器和 TabPFN；分类先复现现有 F/UF 基线。所有原始与派生样本共用拆分规则。

验收：每个样本获得一次外层折外预测，相关几何不跨折；保存逐几何、逐目标指标和失败统计。

P3 · 新三角形力场推理

新增统一 query 网格与多几何模型包，复用特征实现；在物理定义确认后接入 Fzong。完成分辨率与坐标一致性验证。

验收：返回完整查询点、各场结果和覆盖诊断；与独立参考场比较，零交叉及边界位置可核对。

P4 · 端到端聚焦与发布

建立折外预测场数据集，训练并验证级联分类器；比较真实场与预测场分类表现，再冻结发布方案并生成模型包。

验收：外层测试几何在所有上游训练中不可见；用独立标签验收整条链，所有运行可由版本记录复现。

第一版范围建议：先统一显式单位、物理几何分组、FD/FL 独立回归、规则查询网格和 F/UF 判定。把三分类、复杂上游依赖和自适应网格作为后续可独立比较的方案。

需要从数据提供者或研究定义中确认的事项

  1. u 是速度、某个速度分量、力，还是其他量？它与 FL 的目标单位分别是什么？
  2. Fzong / Fzong2 的确切公式、方向、符号和参考坐标系是什么？是否还依赖粒径、黏度等参数？
  3. 文件中的 10/20/30 和列 R 是否是同一种曲率半径？单位是否一致？
  4. 最终需要 F/UF 还是 WF/F/UF？三类的人工判定标准和跨几何标注覆盖是否具备？
  5. 训练批次间的 FD、FL、Fzong 与聚焦标签能否按同一几何及工况准确关联？

这些问题不妨碍先实现审核、契约和评估骨架，但会决定后续力合成与端到端分类是否能够成立。
